ПРОТОТИП САЙТА: ЭКО-УРОКИ
==========================

КАК ОТКРЫТЬ НА КОМПЬЮТЕРЕ
-------------------------
Вариант 1 (проще всего): дважды щёлкните по файлу index.html. Сайт откроется в браузере.

Вариант 2 (Ubuntu, через терминал):
  1. Откройте терминал в этой папке (правая кнопка мыши -> "Открыть в терминале").
  2. Выполните:  python3 -m http.server 8000
  3. Откройте в браузере:  http://localhost:8000
  4. Остановить сервер: Ctrl+C в терминале.

Шрифт Roboto подгружается из интернета. Без интернета сайт тоже работает, но с обычным шрифтом.

КАК ПОСМОТРЕТЬ С ТЕЛЕФОНА (пока работает сервер из варианта 2)
---------------------------------------------------------------
Телефон и компьютер должны быть в одной Wi-Fi сети.
В терминале выполните  hostname -I  и возьмите первое число (например 192.168.1.25).
На телефоне откройте  http://192.168.1.25:8000

КАК ВЫЛОЖИТЬ В ИНТЕРНЕТ БЕСПЛАТНО, ЧТОБЫ ПОКАЗАТЬ ДРУГИМ
--------------------------------------------------------
Вариант A (быстрее всего): Netlify Drop. Найдите страницу Netlify Drop, перетащите на неё
саму папку сайта (ту, где лежит index.html) и получите ссылку.
Вариант B (надёжнее для защиты): GitHub Pages. Создайте репозиторий на GitHub, загрузите
файлы, в настройках репозитория включите Pages.

УПРАВЛЕНИЕ В УРОКЕ
------------------
Клик мыши, пробел, Enter или стрелка вправо  - следующая реплика
(если текст ещё печатается, то первое нажатие показывает его целиком)
Стрелка влево или Backspace                  - предыдущая реплика
Esc или кнопка "Меню"                        - выйти в меню
На телефоне: нажатие на экран. Телефон нужно держать горизонтально.

ГДЕ ЧТО ЛЕЖИТ
-------------
index.html              страница сайта
css/style.css           внешний вид (цвета в самом верху файла)
js/app.js               логика сайта (трогать не нужно)
js/data/common.js       список фонов и героев
js/data/lessons.js      карточки в меню
js/data/lesson1.js      сценарий урока 1 (реплики, фоны, кто появляется). СЮДА ДОБАВЛЯЕМ ТЕКСТ
assets/bg               фоны (16:9)
assets/chars            герои (PNG с прозрачным фоном, обрезаны по колено)
assets/ui               картинки карточек меню
assets/audio            сюда класть озвучку

КАК ЗАМЕНИТЬ КАРТИНКУ
---------------------
Положите новый файл в нужную папку с ТЕМ ЖЕ именем (например, assets/chars/sergey.png).
Пока Сергей и Лиза нарисованы заглушками, их файлы sergey.png и liza.png нужно заменить.

ЗАМЕЧАНИЕ
---------
Название проекта в меню пока заглушка. Его можно изменить в index.html (две строки
"Название проекта": в <title> и в заголовке <h1>).
